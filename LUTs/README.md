# Sample LUTs

Two small 17x17x17 sample `.cube` LUTs. They are bundled into the app and copied to
**Files → On My iPhone → BalutCam → LUTs** on first launch.

To add your own: drop 3D `.cube` files in that folder (or use the in-app Import button),
then tap **Rescan** in the LUT tab. 1D LUTs are not supported; use display-referred (Rec.709) LUTs.
