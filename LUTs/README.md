# LUT folder for BalutCam

Place user-provided LUT files here, such as `.cube` files, and the app will load them for use in film looks and presets.

Example files:
- kodak-portra.cube
- fuji-400h.cube
- agfa-vista.cube

Use a custom folder in the app settings or keep your LUTs under:

~/Documents/BalutCam/LUTs
